# 科研质量护栏与评估标准

## 1. 目标

本文件定义 AI 科研工作的最低质量标准。任何阶段产出未通过质量护栏，不得进入对外写作或发布。

## 2. 引用真实性

### 要求

1. 每条引用必须有可验证来源：DOI、arXiv、URL、会议页、期刊页或仓库页。
2. 引用不得只来自模型记忆。
3. 引文内容必须支持实际写入论文的主张。
4. 不得把相邻但不同的主张合并成一个引用。

### 检查项

| 检查 | 通过标准 |
|---|---|
| 来源存在 | 链接可打开或 DOI/arXiv 可解析 |
| 作者年份正确 | 与原文一致 |
| 主张匹配 | 引用确实支持该句 |
| 无伪造 | citation map 中不存在无源引用 |

### 引用核验等级

| 等级 | 标准 | 可用于论文正文 |
|---|---|---|
| A | DOI/arXiv/出版社页面验证，PDF 已获取，claim 已核对原文 | 可以 |
| B | 元数据验证，摘要核对，但未核对全文 | 可用于背景，不可支撑关键结论 |
| C | 仅搜索结果或二手来源验证 | 不建议 |
| D | 无法验证 | 禁止使用 |

### 自动拒绝条件

| 情况 | 处理 |
|---|---|
| DOI 指向另一篇论文 | 删除引用并登记风险 |
| 标题与作者不匹配 | 删除引用并重新检索 |
| AI 无法找到原文证据 | 降级为待核验，不得进入正文 |
| 引用内容与论文结论相反 | 标记为误引，要求人工审核 |

## 3. 论文事实抽取

### 要求

AI 必须区分：

1. 原文明确陈述。
2. AI 根据原文推断。
3. AI 的评价。
4. 人类决策。

### 证据等级

| 等级 | 含义 | 可用于论文主张 |
|---|---|---|
| A | 原文直接支持 | 可以 |
| B | 多处证据间接支持 | 谨慎使用 |
| C | AI 推断 | 不得作为核心主张 |
| D | 未验证 | 不得使用 |

## 4. 实验可复现

每个实验必须记录：

1. 代码版本或 commit。
2. 数据集名称、版本、来源、许可证。
3. 环境和依赖。
4. 随机种子。
5. 运行命令。
6. 原始日志。
7. 原始结果。
8. 处理脚本。
9. 生成图表的脚本或流程。

若任一项缺失，结果只能标记为 preliminary，不得作为最终结论。

### 可复现等级

| 等级 | 标准 |
|---|---|
| R0 | 无代码、无数据、无环境记录，不可复现 |
| R1 | 有部分代码或伪代码，可人工复现 |
| R2 | 有代码和数据说明，但环境不完整 |
| R3 | 有完整代码、数据、环境、seed，可单机复现 |
| R4 | 有容器、自动脚本、CI 或 workflow，可自动复现 |
| R5 | 第三方或独立 Agent 成功复现并记录结果 |

## 5. 统计分析

AI 必须检查：

1. 样本量是否足够支撑结论。
2. 是否需要置信区间或显著性检验。
3. 是否存在 cherry-picking。
4. 是否报告失败样本。
5. 是否区分主实验和探索性实验。

禁止：

1. 看结果后更换主指标却不记录。
2. 只报告最好的一次运行。
3. 把探索性结果写成 confirmatory result。

## 6. 伦理与合规

AI 必须识别以下风险：

1. 人类受试者。
2. 个人隐私。
3. 医疗、法律、金融建议。
4. 双重用途。
5. 数据版权和许可。
6. 论文写作诚信。
7. 署名和贡献不实。

涉及上述风险时，AI 必须写入 `DECISIONS.md` 并等待人审。

### 伦理风险等级

| 等级 | 标准 | 动作 |
|---|---|---|
| E0 | 无明显伦理风险 | 自动继续 |
| E1 | 低风险公开数据 | 自动继续，归档来源 |
| E2 | 数据许可或隐私边界不清 | 登记，等待人工确认 |
| E3 | 涉及敏感个人、医疗、未成年人或双重用途 | 停止相关任务，必须人工审核 |
| E4 | 明显违法、违规、伤害性用途 | 拒绝执行并记录 |

## 7. 幻觉防控

AI 产出必须标注置信度：

| 标签 | 含义 |
|---|---|
| `verified` | 已有来源或实验支持 |
| `inferred` | AI 推断，需人类或证据确认 |
| `unverified` | 未验证，不得进入论文正文 |
| `decision` | 来自人类决策 |

任何 `unverified` 内容不得进入最终论文、摘要、贡献点或结论。

## 8. 审稿模拟标准

每篇论文草稿至少经过五类审稿：

1. Novelty：创新性是否足够。
2. Soundness：方法和实验是否支撑结论。
3. Reproducibility：代码、数据、参数是否可复现。
4. Clarity：表达是否清楚。
5. Ethics：是否存在伦理、署名、风险披露问题。
6. CCF C Reviewer Agent：按 CCF C 会审稿视角检查是否达到最低投稿可信度。

每个 reviewer Agent 必须给出：

1. 分数。
2. 主要优点。
3. 主要缺陷。
4. 拒稿风险。
5. 必须修改项。
6. 可选修改项。

### CCF C Reviewer Gate

论文进入投稿前，必须完成 `CCF_C_REVIEWER_AGENT.md` 定义的 CCF C 审稿检查。

通过条件：

| 检查项 | 通过标准 |
|---|---|
| 推荐等级 | 不低于 `Borderline`，且人类明确接受风险 |
| 一票否决项 | 无未解决项 |
| P0/P1 风险 | 已解决，或已写入 `DECISIONS.md` 并经人类确认 |
| 主张强度 | 摘要、贡献点、结论均通过 Claim Strength Audit |
| 实验充分性 | baseline、主实验、消融、失败案例或边界分析足以支撑主张 |
| 复现性 | 核心实验至少达到 R3 |

若推荐等级为 `Weak Reject-level` 或 `Reject-level`，不得进入投稿动作，只能继续补证据、补实验、改写定位或等待人类决策。

## 9. 论文主张强度控制

| 表述强度 | 使用条件 |
|---|---|
| “我们提出” | 方法确实由本研究定义 |
| “我们观察到” | 实验或分析支持，但不宜泛化 |
| “结果表明” | 主实验和统计分析支持 |
| “显著优于” | 有统计检验或充分重复实验 |
| “首次” | 完成系统性查新并经人审 |
| “SOTA” | 覆盖公认 benchmark 且经人审 |

AI 默认应使用保守表述。强主张必须进入人审。

## 10. 阶段通过标准

| 阶段 | 通过标准 |
|---|---|
| 文献阶段 | 核心论文有论文卡片，关键引用可追溯 |
| 假设阶段 | 每个候选假设有证据、风险、实验路径 |
| 实验阶段 | 协议冻结，结果可复现 |
| 分析阶段 | 结论和结果匹配，负面结果已记录 |
| 写作阶段 | 每个关键主张有 citation 或实验依据 |
| 投稿前 | 所有人审项关闭，复现包完整 |

## 11. 最终质量门禁

在生成最终论文、报告、PPT 或公开材料前，必须通过以下门禁：

| 门禁 | 通过标准 |
|---|---|
| Citation Gate | 所有正文引用达到 A/B 级，关键引用必须 A 级 |
| Fact Gate | 所有关键 claim 均在 Claim-Evidence Matrix 中 |
| Reproducibility Gate | 核心实验至少达到 R3，推荐达到 R4 |
| Statistics Gate | 统计方法、效应量、不确定性、多重比较已审核 |
| Ethics Gate | 无未解决 E2+ 风险 |
| Hallucination Gate | 无未证实 claim 进入正文 |
| Review Gate | 至少完成 3 类 Reviewer 模拟审稿，且包含 CCF C Reviewer Agent |
| Archive Gate | 文献、数据、代码、实验、决策、AI 使用记录已归档 |
| Human Approval Gate | 人类确认最终结论、署名、投稿和公开发布 |
